# 📦 RotaEntrega Pro

    App PWA de entregas com:
    - 📸 OCR — tira foto da folha e reconhece endereços
    - 🗺️ Otimização de rota
    - 🚗 Integração Google Maps / Waze
    - ✍️ Assinatura digital do cliente
    - 🔊 Alertas por voz
    - 📲 **Compartilhamento pelo WhatsApp após cada entrega**

    ## Como usar

    1. Abra o app no celular
    2. Tire foto da folha de endereços
    3. Configure a rota e inicie
    4. Navegue com Google Maps ou Waze
    5. Capture assinatura do cliente
    6. Dê baixa → **app pergunta se deseja enviar comprovante pelo WhatsApp**

    ## Instalar no celular

    1. Acesse o link do GitHub Pages no Chrome
    2. Menu (3 pontos) → "Adicionar à tela inicial"
    3. Use como app nativo!

    ## Tecnologias
    - Tesseract.js (OCR)
    - HTML5 Canvas (assinatura)
    - Web Speech API (voz)
    - Google Maps / Waze (navegação)
    - WhatsApp API (compartilhamento)

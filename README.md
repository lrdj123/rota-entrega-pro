# 📦 RotaEntrega Pro

    App PWA de entregas com:
    - 📸 OCR — reconhece endereços por foto
    - 🗺️ Otimização de rota
    - 🚗 Google Maps / Waze
    - ✍️ Assinatura digital do cliente
    - 🔊 Alertas por voz
    - 📲 **Compartilhar comprovante pelo WhatsApp após cada entrega**

    ## Como usar

    1. Abra no celular
    2. Tire foto da folha ou digite os endereços
    3. Configure a rota e inicie
    4. Navegue com Google Maps ou Waze
    5. Capture a assinatura do cliente
    6. Dê baixa → app pergunta se quer enviar comprovante pelo WhatsApp para o dono

    ## Instalar no celular

    1. Abra o link do GitHub Pages no Chrome
    2. Menu (3 pontos) → "Adicionar à tela inicial"

    ## Tecnologias
    - Tesseract.js (OCR)
    - HTML5 Canvas (assinatura)
    - Web Speech API (voz)
    - WhatsApp API (compartilhamento)
